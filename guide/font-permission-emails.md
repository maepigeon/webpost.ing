# Asking for the dafont fonts — emails for Mae to send

Three of the five fonts only need the designer's yes. Send these from your
own address; keep the replies (forward them into `guide/` or save a PDF) as
your proof of permission. Addresses are the ones shown on each font's dafont
page (see [fonts-dafont-licences.md](fonts-dafont-licences.md)); check them
there before sending. Once a designer says yes, download the font yourself,
put the file in `client/public/fonts/`, and tell the AI session: it will wire
it in the same way as Choco Cooky (served with the site, kept out of the
public repository).

## What to ask for (all three)

- Permission to **self-host the font as a web font** on webpost.ing (visitors'
  browsers download it to display text), and to offer it in the site's font
  picker so members can use it in their own posts and profiles.
- Whether credit is wanted, and how it should read.
- Whether a donation or fee applies.

## The other two need a purchase

- **Tritopani** (Ergibi Studio): the dafont file is a demo. Buy a licence from
  the designer's shop and check that it covers **web font / @font-face** use
  and the number of visitors.

  licence is sold by the designer. Ask whether it covers web hosting before
