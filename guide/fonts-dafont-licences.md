## Notes

- No font here is "100% free", OFL, public domain or GPL. All are dafont "Free for personal use". Serving the file to every visitor, and offering it in a picker, is redistribution, which that label does not cover. Non-commercial site status does not change this: "personal use" means the person using it privately, and a public site republishing the file is not that.
- Three are realistically obtainable: Champagne & Limousines (email nymphont@yahoo.com, donation), SquirmFont (email alex@floatpointgames.com), Magnificent Serif (contact imagex via https://www.imagex-fonts.com). Get the permission in writing and explicitly mention web embedding/redistribution as web font files.
- Tritopani and The Punk Grandmother point at paid commercial licences; check that any purchased licence includes web/@font-face use.
- Alternatives are named from my own knowledge of Google Fonts (OFL) for visual similarity; I did not fetch or verify their pages. Check each one's licence on fonts.google.com before adding.
- Unverified: the Champagne web-embedding wording (search snippet only); the exact "Tritopani" and "Magnificent Serif" dates shown by the fetcher look odd (2026 dates), which is fine for today's date but not independently checked; the Punk Grandmother page slug was fetched successfully.
